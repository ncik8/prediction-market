# Prediction Market Demo - Project Plan

## Tech Stack
- Frontend: Next.js + TailwindCSS
- Backend: Next.js API Routes
- Database: PostgreSQL (via Prisma)
- Auth: Telegram (already have)

## Features
1. Fake $10,000 balance for each user
2. Create crypto prediction markets
3. Buy Yes/No shares
4. Trade in/out of positions
5. Auto-resolve based on price data (or admin)

## Markets to Start
- BTC price milestones
- ETH predictions
- Altcoin events
